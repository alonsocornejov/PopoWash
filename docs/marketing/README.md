# Cuaderno de marketing y marca de PopoWash

Abre [PopoWash-cuaderno-de-marca.html](PopoWash-cuaderno-de-marca.html) en un navegador con JavaScript habilitado. Es un documento autónomo, sin dependencias externas, con 83 campos para completar, además de nombre y fecha:

1. Producto y oferta.
2. Objetivos y público.
3. Brief de marketing.
4. Manual de marca.

Completa las secciones con la información del equipo. Los antecedentes de reuniones deben distinguirse de las decisiones confirmadas; el cuaderno pendiente de completar y aprobar todavía no constituye un manual de marca vigente.

## Guardar, compartir e imprimir

- **Guardado automático:** conserva las respuestas en el navegador cuando el almacenamiento local está disponible. No sincroniza entre equipos o navegadores.
- **Guardar copia:** descarga un archivo HTML con las respuestas incorporadas. Usa esta opción para conservar una copia y compartirla; quien la reciba podrá abrirla y seguir completándola.
- **Descargar respuestas:** exporta las respuestas como un archivo Markdown.
- **Imprimir:** incluye las cuatro secciones, aunque solo una esté visible. La versión vacía se verificó en 12 páginas; el contenido añadido puede aumentar la extensión.

El cuaderno no conecta servicios ni envía datos. Las respuestas quedan en el navegador y en los archivos que se descarguen y compartan.

## Alcance y comprobaciones

Se verificaron la navegación, los 83 campos, la persistencia al recargar, el guardado y reapertura con caracteres especiales, la exportación en móvil y la impresión completa, incluida una respuesta larga sin pérdida de contenido. La revisión visual cubrió escritorio de 1365 px y móvil de 390 px.

El diseño es neutro para trabajo interno: papel blanco, títulos negros, Georgia para el título, Segoe UI/Arial para el cuerpo y controles azules. No modifica la identidad de la web ni requiere crear `PRODUCT.md` o `DESIGN.md` del sitio.

Consulta [Skills de marketing](SKILLS-MARKETING.md) para conocer las tres colecciones instaladas, sus usos y los requisitos de sus integraciones. Una vez aprobado el contenido del cuaderno, la información validada puede servir como contexto para esas skills.
