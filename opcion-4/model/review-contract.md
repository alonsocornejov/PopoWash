# Contrato de revisión leído

Se leyeron completas las instrucciones `grimoire/review/gates_reference.md`, `grimoire/review/self_correction.md`, `grimoire/feedback/render_capture.md`, `grimoire/readiness/joint_attachment.md`, `grimoire/readiness/action_rigging.md` y `grimoire/feedback/shading_realism.md` de img2threejs.

La autoridad geométrica son las fotografías originales 000, 045 y 180, no las nuevas imágenes generadas para el hero. La segmentación manual de 000 se utiliza sólo para diagnóstico, no como modelo. La normalización del encuadre sólo admite escala uniforme y traslación, sin deformación. Las revisiones visuales se registran después de los controles deterministas, usando la hoja comparativa y las vistas de los costados. Un control numérico no aprueba por sí solo realismo 3D.

Intersecciones: se muestrean 128 vértices por malla para una primera comprobación acotada; se conserva en el informe el número realmente analizado. No prueba ausencia de cualquier intersección. Unidades y caras ocultas inferidas; no es un modelo dimensional ni de fabricación.
