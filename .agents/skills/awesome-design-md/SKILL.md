# Awesome Design MD para PopoWash

Esta skill es una adaptación local. El repositorio original es una colección de análisis de diseño, no una skill ejecutable ni documentación oficial de esas marcas.

1. Lee el encargo y `docs/CONTEXTO.md` desde la raíz del proyecto. Revisa la propuesta web indicada y cualquier dirección visual ya acordada.
2. Consulta [CATALOGO.md](CATALOGO.md) y abre solo los `DESIGN.md` pertinentes dentro de `references/`. Si no se ha elegido una referencia, propone dos o tres opciones con una explicación breve de qué aportaría cada una.
3. Extrae principios útiles: jerarquía, tipografía, espaciado, contraste, componentes y comportamiento móvil. Distingue la referencia externa de las decisiones propias de PopoWash. Conserva la marca y los hechos del producto salvo que el encargo pida cambiarlos.
4. Cuando el usuario pida implementar una dirección concreta, aplícala a la propuesta indicada y comprueba escritorio y móvil. Un pedido de inspiración o comparación no autoriza a rediseñar las páginas.
5. Escribe un `DESIGN.md` del proyecto solo cuando se haya solicitado documentar o establecer esa dirección. No copies automáticamente un documento de otra marca a la raíz ni trates el catálogo completo como instrucciones simultáneas.

Las referencias incluyen nombres de fuentes, imágenes y servicios externos; comprueba su disponibilidad antes de depender de ellos. La instalación del catálogo no instala esas fuentes o servicios.
